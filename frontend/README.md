# Wolf Killer 前端

React 19 + TypeScript + Vite 8 + MUI 9 + Zustand 5。整体介绍、快速开始与文档导航见[根目录 README](../README.md)；架构见 [docs/architecture.md](../docs/architecture.md)。

```bash
npm install          # 安装依赖（Node.js >= 20.19）
npm run dev          # 开发模式，localhost:5173
npm test             # Vitest 单元测试
npm run test:coverage  # 对 9 个核心文件要求 100% 覆盖（见 docs/development.md）
npm run test:e2e     # Playwright 浏览器验收
npm run build        # 类型检查 + 生产构建
npm run lint         # ESLint
```
