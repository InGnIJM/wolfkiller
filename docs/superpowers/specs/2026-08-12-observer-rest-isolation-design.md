# 旁观者 REST 数据隔离设计

## 目标

在无认证旁观者模式下，所有 REST 读取接口只暴露公开游戏信息。身份在死亡和游戏结束后仍永久保密。

## 边界

本次处理 `GET /api/games/{game_id}` 与该局日志读取接口；不引入玩家令牌、登录或身份视图。未知游戏在两个接口均返回 404。

## 游戏详情

详情路由不得序列化内部 `GameState`、玩家对象或存档字典，而应基于 `state.get_public_state()` 构造封闭 DTO。DTO 只包含界面所需的公开座位、存活状态、当前阶段、轮次、公开投票/死亡结果与胜负结果。

DTO 禁止包含以下字段或其等价信息：`role`、`role_id`、`camp`、`faction`、`resources`、女巫药剂、猎人枪、狼人队友、夜间目标、推理/思考或任意可由其反推出身份的私有字段。未知字段默认不随模型转发。

## 公开回放

日志接口返回经过白名单投影的时间线事件，而不是原始 `game.log` / 对话记录。仅保留：公开发言、公开投票、公开死亡、阶段变化和胜负。日志初始化身份、夜间行动、狼人频道、模型对话、prompt、thought、私有 action 参数及未知事件均丢弃。

回放事件只使用公开字段：事件类型、轮次/阶段、公开座位和用户可见文本；过滤器不为历史数据补全或猜测信息。不能安全投影的事件直接忽略。

## 前端契约

前端 API client、`GameBoard`、`gameStore` 与类型声明消费上述公开 DTO 和公开时间线。删除任何读取 `role_init`、玩家角色、阵营、资源、夜间行动或原始日志字段的路径。界面不以死亡或游戏结束为由显示身份。

## 验收

1. 两个未知 game id 都是 404。
2. 详情序列化与日志响应的递归 JSON 中不含禁止字段或身份值。
3. 公开发言、投票、死亡、阶段与胜负仍可回放。
4. 前端类型检查和相关测试通过，且没有 `role_init` 消费方。
