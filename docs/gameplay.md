# 游戏规则与流程

本文描述 Wolf Killer 的对局规则、角色能力与游戏流程。规则由 `backend/app/core/rule_engine.py`（胜负判定）、`backend/app/core/state_machine.py`（阶段流转）与 `backend/app/core/game_engine.py`（流程编排）实现。

## 角色配置

默认预设为 9 人局（`backend/app/catalog.py`），另有附带守卫的 10 人局预设可选：

| 阵营 | 角色 | 默认人数 | 能力 |
| ---- | ---- | -------- | ---- |
| 好人 | 平民 | 3 | 无特殊能力，通过发言和投票找出狼人 |
| 好人 | 预言家 | 1 | 每晚查验一名玩家的阵营 |
| 好人 | 女巫 | 1 | 一瓶解药（救人）+ 一瓶毒药（杀人），各限一次；解药只能救当晚刀口，且自救（救自己）仅限第一晚 |
| 好人 | 猎人 | 1 | 死亡时可开枪带走一名玩家 |
| 狼人 | 狼人 | 3 | 每晚共同决定击杀一名玩家，互相知道身份 |
| 好人 | 守卫 | 0（10 人局预设为 1） | 样例角色，用于验证角色扩展流水线 |

角色目录（名称、图标、约束）通过 `GET /api/catalog/roles`、`GET /api/catalog/presets`、`GET /api/catalog/constraints` 暴露给前端。

## 板子选项

- **明牌局（`reveal_on_death`，默认关闭）**：开启后，玩家出局（夜晚死亡、放逐、猎人开枪带走）时立即公开身份——系统向公开频道播报身份公告，其余 Agent 的后续发言/投票上下文与狼队夜间简报中都会看到；前端死亡公告弹窗同步显示身份。

## 游戏流程

```
发放身份 → 夜晚 → 天亮了 → 遗言 → 顺序发言 → 投票放逐 → 夜晚（循环）
```

### 夜晚

- **狼人**：狼队先内部讨论，再共同投票决定刀口目标。
- **女巫**：存活女巫每晚都能获知当晚刀口，与剩余药品无关；两瓶药用完后仍能获取信息，但只能选择不使用药水。无狼刀时刀口为空；刀口只提供给女巫本人，不向其他角色公开。
- **预言家**：查验一名玩家的阵营。
- **猎人**：死亡（含被放逐，经流水线反应调度点）时可开枪带走一名玩家。
- 夜晚结算（`core/night_settlement.py`）汇总待定伤害与保护，产出死亡批次。

### 白天

1. 公布夜间死亡。
2. 仅首夜被狼刀或女巫毒杀的死者逐一发表遗言；第二夜起的夜间死者不发表遗言。
3. 顺序发言：存活玩家从**最近死亡玩家的下一位存活玩家**开始按座位号依次发言（`game_engine.py` 的 `_execute_speech_round`；尚无死亡记录时从最小存活座位开始）。
4. 投票放逐，被放逐者发表遗言。

本局**没有警长**：不竞选警长、不发警徽、预言家也不用报「警徽流」。白天只有遗言、顺序发言和投票。

### 遗言资格

- 只有**首夜**被狼人刀杀或被女巫毒杀的玩家可以发表遗言。
- 被放逐的玩家在任意轮次都可以发表遗言。
- 猎人开枪带走的玩家，以及自爆、殉情等其他死亡原因，均不能发表遗言。

### 平票处理

平票时进入**恰好一轮**补充发言 + 复投（`vote_round=2`，见 `_execute_tiebreak`）；复投若仍平票，则本轮无人被放逐。

## 胜利条件

- **好人阵营**：放逐所有狼人。
- **狼人阵营**：屠边——消灭所有神职（预言家/女巫/猎人）或所有平民。
- **狼刀在先**：若双方同时满足胜利条件，狼人阵营优先获胜（`rule_engine.py` 先判定狼人胜利条件）。
