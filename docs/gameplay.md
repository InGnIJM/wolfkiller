# 游戏规则与流程

本文描述 Wolf Killer 的对局规则、角色能力与游戏流程。规则由 `backend/app/core/rule_engine.py`（胜负判定）、`backend/app/core/state_machine.py`（阶段流转）与 `backend/app/core/game_engine.py`（流程编排）实现。

## 角色配置

默认预设为 9 人局（`backend/app/catalog.py`），另有附带守卫的 10 人局预设，以及两套 12 人板子（`twelve-player-idiot`：4 狼 4 民 预女猎白痴；`twelve-player-wolf-king`：3 狼 1 白狼王 4 民 预女猎守）：

| 阵营 | 角色 | 默认人数 | 能力 |
| ---- | ---- | -------- | ---- |
| 好人 | 平民 | 3 | 无特殊能力，通过发言和投票找出狼人 |
| 好人 | 预言家 | 1 | 每晚查验一名玩家的阵营 |
| 好人 | 女巫 | 1 | 一瓶解药（救人）+ 一瓶毒药（杀人），各限一次；解药只能救当晚刀口，且自救（救自己）仅限第一晚 |
| 好人 | 猎人 | 1 | 死亡时可开枪带走一名玩家 |
| 狼人 | 狼人 | 3 | 每晚共同决定击杀一名玩家，互相知道身份 |
| 好人 | 守卫 | 0（10 人局预设为 1） | 每晚守护一名存活玩家，不能连续两晚守同一人；只抵消狼刀，毒药与猎枪无视守护；与女巫解药同时守/救同一狼刀目标时，该目标仍死亡（对穿） |
| 好人 | 白痴 | 0（12 人白痴板为 1，`max_count=1`） | 被投票放逐时自动翻牌：公开身份、不出局、失去投票权、之后不再能被放逐，仍可发言；夜间被刀/毒、被猎枪或白狼王带走时正常死亡。计入神职 |
| 狼人 | 白狼王 | 0（12 人白狼王板为 1，`max_count=1`） | 夜晚与狼队共同讨论/刀人。白天发言阶段每位玩家发言前可选择**自爆**并带走一名存活玩家，两人均出局、无遗言，当日剩余发言与投票取消直接入夜；被毒/放逐/枪杀时普通出局，不能带人 |

角色目录（名称、图标、约束）通过 `GET /api/catalog/roles`、`GET /api/catalog/presets`、`GET /api/catalog/constraints` 暴露给前端。

## 板子选项

- **明牌局（`reveal_on_death`，默认关闭）**：开启后，玩家出局（夜晚死亡、放逐、猎人开枪带走）时立即公开身份——系统向公开频道播报身份公告，其余 Agent 的后续发言/投票上下文与狼队夜间简报中都会看到；前端死亡公告弹窗同步显示身份。

## 游戏流程

```
发放身份 → 夜晚 → 天亮了 → 遗言 → 顺序发言 → 投票放逐 → 夜晚（循环）
```

### 夜晚

引擎按分阶段检查点执行（`GameEngine._execute_staged_night`），顺序是：

1. 若本局有守卫：旁白「守卫请睁眼」，再跑 `NIGHT_ACTION`（守卫守护或 pass）。
2. 狼队内部讨论（多名存活狼时串行发言），再逐一投票；随后 `NIGHT_WOLF_VOTE` 提交刀口。
3. 女巫获知刀口后行动（`NIGHT_WITCH_ACTION`）。
4. 预言家查验（`NIGHT_SEER_ACTION`）。
5. `NIGHT_COMMIT` 结算伤害/保护，并触发猎人等响应窗口。

角色能力：

- **守卫**：每晚守护一名存活玩家或选择不守护；**不能连续两晚守护同一座位**；守护只抵消狼刀，**毒药与猎枪无视守卫**。
- **狼人 / 白狼王**：狼队先内部讨论，再共同投票决定刀口目标。狼队成员按阵营（`camp == werewolf`）识别，白狼王与普通狼人共享同一条 `werewolf_kill` 契约合并计票。
- **女巫**：存活女巫每晚都能获知当晚刀口，与剩余药品无关；两瓶药用完后仍能获取信息，但只能选择不使用药水。无狼刀时刀口为空；刀口只提供给女巫本人，不向其他角色公开。
- **预言家**：查验一名玩家的阵营。
- **猎人**：死亡（含被放逐，经流水线 `DAWN_REACTION` 调度点）时可开枪带走一名玩家。

**对穿**：守卫守护与女巫解药同时作用于同一狼刀目标时，该目标仍然死亡（`night_settlement.py` 的 double-save penetration）。普通「守住」或「解药」单独生效时可以抵消狼刀。守护和解药都不抵消毒药或猎枪。

夜晚结算汇总待定伤害与保护，产出死亡批次。

### 白天

1. 公布夜间死亡。
2. 仅首夜被狼刀或女巫毒杀的死者逐一发表遗言；第二夜起的夜间死者不发表遗言。
3. 顺序发言：存活玩家从**最近死亡玩家的下一位存活玩家**开始按座位号依次发言（`game_engine.py` 的 `_execute_speech_round`；尚无死亡记录时从最小存活座位开始）。每位发言者开口前引擎跑一次 `DAY_ACTION` 调度点（`slot` 为 `vote_round:seat`）；若有角色提交 `DAY_INTERRUPTED`（当前只有白狼王自爆），则结算双死、触发 `DAWN_REACTION`（被带走的猎人可开枪）、播报「自爆，本日发言与投票取消」并直接进入夜晚（状态机事件 `WEREWOLF_EXPLODED`）。
4. 投票放逐。得票最高者先经 `EXILE_VERDICT` 调度点裁决：若有角色提交 `EXILE_CANCELLED`（当前只有白痴翻牌），则公开身份（`PLAYER_REVEALED`）、该座位获得 `no_vote` 与 `exile_immune` 状态、投票结果记为「无人出局」且不走遗言；否则正常放逐，被放逐者发表遗言。
5. 投票资格读取运行时状态：带 `no_vote` 的座位不再投票，带 `exile_immune` 的座位不再出现在候选中（提示词会列出免于放逐的座位）。

本局**没有警长**：不竞选警长、不发警徽、预言家也不用报「警徽流」。白天只有遗言、顺序发言和投票。

### 遗言资格

- 只有**首夜**被狼人刀杀或被女巫毒杀的玩家可以发表遗言。
- 被放逐的玩家在任意轮次都可以发表遗言。
- 猎人开枪带走的玩家不能发表遗言。
- 白狼王自爆（死因 `self_explode`）的本人与被带走者都不发表遗言。`DeathReport` 仍保留 `love_death` 等未实现死因枚举，即便出现也不给遗言。
- 白痴翻牌免于出局，不算死亡，也没有遗言环节。

### 平票处理

平票时进入**恰好一轮**补充发言 + 复投（`vote_round=2`，见 `_execute_tiebreak`）；复投若仍平票，则本轮无人被放逐。

## 胜利条件

判定顺序由 `rule_engine.py` 固定为先狼后好人（「狼刀在先」）：

- **狼人阵营**（任一即胜）：
  - 场上存活神职为 0（预言家 / 女巫 / 猎人 / **守卫** / **白痴** 均计入神职；翻牌后的白痴只要存活就仍算神职）
  - 场上存活平民为 0
  - 存活狼人人数 **大于** 存活好人人数（狼人数含白狼王）
- **好人阵营**：存活狼人（含白狼王）为 0。
