## 一、跑测前置准备（每次跑测都要做）

```bash
# 1. 从干净基线开始，记录基线 commit
cd <REPO_PATH>
git status --porcelain          # 必须为空
git rev-parse HEAD              # 记为 BASE_SHA

# 2. 让被测模型在仓库中完成改动（把 DELIVER 全文投喂，替换 <REPO_URL>/<REPO_PATH>）

# 3. 跑测结束后，冻结产出并取 diff
git diff --stat                 # 改动范围
git status --porcelain          # 新增文件
git diff > /tmp/eval_<model>.patch
```

> 每换一个模型，**必须先恢复到 BASE_SHA 的干净状态**（`git checkout . && git clean -fd`），否则改动会串味。

- **G1 / G2 任一失败 → G 维度直接 0 分**，且总分不得高于 60（交付物在真实仓库里跑不起来）。
