狼人杀发言顺序问题 — 解决方案

问题：玩家轮流发言时，后面发言的玩家会评价尚未发言的玩家"沉默"或"不说话"，这不符合现实逻辑——未发言的玩家只是还没轮到而已。

一、问题根因分析

当前代码行为

在 game_engine.py 的 _execute_speech_round() 中：

async def _execute_speech_round(self) -> None:
    alive = list(self.state.alive_players().items())
    for seat, player in alive:          # 按座位号顺序遍历
        speech_text = await self.speak(seat, "day_speech")
        # ... 记录发言到 conversation_log

玩家确实按顺序发言，但 LLM 收到的 prompt 中没有明确告知：

  • 当前是第几位发言
  • 本轮发言的完整顺序是什么
  • 哪些人已经发过言、哪些人还没轮到
  • 「未发言 ≠ 沉默不发言」这条关键规则

LLM 只能看到 conversation_log 中按时间排列的发言记录。如果第 3 号玩家还没发言，第 5 号玩家看到的 log 里没有 3 号的发言，LLM 可能会错误推断"3 号故意不说话"——实际上 3 号只是还没轮到。

二、解决方案总览

核心思路：在每个玩家的发言 prompt 中，显式注入"发言进度信息"，让 LLM 明确知道谁已经说过、谁还没轮到、以及自己处于什么位置。

修改文件改动内容
修改 app/models/game.py GameState 新增 speaking_order 和 current_speaker 字段
修改 app/core/game_engine.py _execute_speech_round() 中设置发言顺序、标记当前发言者
修改 app/agents/prompt_builder.py 新增发言进度区块；增强 day_speech 任务指令；优化对话记录展示

修改 ②：新增 _format_speaking_progress() 方法

def _format_speaking_progress(self, state: GameState, seat: int) -> str:
    """生成发言进度信息，让 LLM 明确知道谁发过言、谁还没发言。"""
    order = state.speaking_order
    if not order:
        return "（当前不是发言阶段）"

    total = len(order)
    try:
        pos = order.index(seat) + 1
    except ValueError:
        pos = 0

    # 已发言的玩家（在当前发言者之前的）
    already_spoken = [s for s in order if order.index(s) < order.index(seat)]
    # 尚未发言的玩家
    yet_to_speak = [s for s in order if order.index(s) > order.index(seat)]

    lines = []
    lines.append(f"发言总人数：{total}人")
    lines.append(f"发言顺序：{' → '.join(f'{s}号' for s in order)}")
    lines.append(f"当前发言者：{seat}号（你是第 {pos}/{total} 位发言）")

    if already_spoken:
        lines.append(f"已发言：{'、'.join(f'{s}号' for s in already_spoken)}")
    else:
        lines.append("已发言：无（你是第一个发言）")

    if yet_to_speak:
        lines.append(f"尚未发言：{'、'.join(f'{s}号' for s in yet_to_speak)}")

    lines.append("")
    lines.append("⚠️ 重要规则：")
    lines.append("- 尚未发言的玩家不是「沉默」或「不发言」——他们只是还没轮到。")
    lines.append("- 不要因为后面的玩家还没说话就怀疑他们。")
    lines.append("- 你只能评价已经发过言的玩家的发言内容。")

    return "\n".join(lines)

四、系统提示词补充规则

在 SYSTEM_PROMPT 的「发言与行为规范」部分追加以下内容：

## 发言顺序规则（极其重要）

- 每轮白天发言，玩家按座位顺序依次发言
- 系统会在你的 prompt 中明确告知：发言顺序、你当前是第几位、谁已发言、谁尚未发言
- **严禁评价尚未发言的玩家**：还没有轮到的人不叫"沉默"、"划水"或"不敢说话"
- 比如 5 号发言时，7 号还没说话，这不代表 7 号有问题——只是他还没轮到
- 只有已经发过言的人，你才能基于他们的发言内容进行评价和推理
- 如果上轮某人没说话，那是因为你不在那轮或者他在那轮已经出局了——重新检查存活状态
